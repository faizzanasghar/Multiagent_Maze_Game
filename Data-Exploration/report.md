# Data Exploration: Maze Generation Algorithms

## Objective
Analyze and compare the characteristics of DFS, BFS, and Prim's algorithms for maze generation.

## Dataset
The dataset was generated by running 50 iterations of each algorithm on a 15x15 logical grid. Metrics recorded include:
- **Dead Ends**: Count of cells with only one neighbor.
- **Path Length**: Shortest path distance from start to exit.
- **Average Branching**: Average number of open neighbors per path cell.

## Findings
1. **DFS** produces the longest paths but has a relatively low number of dead ends. This confirms its tendency to create long, non-branching corridors.
2. **BFS** results in the shortest possible paths between the start and exit. It expands uniformly, making it less suitable for "challenging" mazes.
3. **Prim's Algorithm** creates a very high number of dead ends. The maze feels very "busy" and branched, though the main path is often shorter than DFS.

## Visualizations
The `analysis.ipynb` (to be viewed in Jupyter) provides histograms and scatter plots showing the distribution of these metrics across algorithms.

## Conclusion
For a game that requires exploration, **DFS** is superior due to its corridor-focused structure. **Prim's** is a good alternative for high-complexity mazes.
